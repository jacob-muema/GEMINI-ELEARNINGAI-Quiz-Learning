04

Data Security & Cryptographic Storage

Security is central to our engineering architecture:

  • Password Hashing: All passwords are salted and hashed using industry-standard one-way cryptographic algorithms (PBKDF2/SHA-256 via Werkzeug). Passwords cannot be decrypted or viewed by platform administrators.
  • Database Protection: User accounts, quiz performance histories, and study progress records are preserved in an encrypted, isolated local relational database.
  • OAuth 2.0 Compliance: Google sign-in handshakes strictly adhere to Google's OpenID Connect protocols with cryptographic token verification.
